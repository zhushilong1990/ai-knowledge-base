# 需求文档

## v1 需求

### 身份认证（AUTH）

- [ ] **AUTH-01**：用户可以注册和登录
- [ ] **AUTH-02**：JWT Token 认证，支持刷新 Token
- [ ] **AUTH-03**：用户可以登出

### RAG / 文档处理（RAG）

- [ ] **RAG-01**：用户可以上传 PDF/Word/TXT 文档
- [ ] **RAG-02**：系统自动解析文档并生成向量，存入 Chroma
- [ ] **RAG-03**：用户可以通过对话提问，AI 基于知识库检索结果生成答案

### 知识库管理（KB）

- [ ] **KB-01**：用户可以查看自己的知识库列表
- [ ] **KB-02**：用户可以删除知识库中的文档

### 聊天 / 对话（CHAT）

- [ ] **CHAT-01**：用户可以和 AI 进行多轮对话
- [ ] **CHAT-02**：对话历史保存，可回溯
