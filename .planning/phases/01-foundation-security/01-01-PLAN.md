    **pom.xml dependencies:**
    - spring-boot-starter-web

    **JwtConfig.java** — loads from application.yml:
    - jwt.secret (min 256-bit)
    - jwt.access-ttl: 900000 (15 min)
    - jwt.refresh-ttl: 604800000 (7 days)

    **JwtTokenProvider.java** — per 01-RESEARCH.md Pattern 2:
    - generateAccessToken(User) — claims: userId, type="access", 15 min expiry
    - generateRefreshToken(User) — claims: type="refresh", 7 days expiry
    - validateToken(String) — returns boolean, catches JwtException
    - getUsernameFromToken(String)
    - getRemainingTime(String) — for proactive refresh
    - Uses SecretKey from jwt.secret, signWith(secretKey)

    **User entity** — per 01-RESEARCH.md Database Schema:
    - Table: users (id BIGINT AUTO_INCREMENT PK, email VARCHAR(255) UNIQUE NOT NULL, password_hash VARCHAR(255) NOT NULL, created_at TIMESTAMP, updated_at TIMESTAMP)
    - MyBatis-Plus @TableName("users"), @TableId(type=IdType.AUTO)
    - @TableField("password_hash") for passwordHash field
    - email unique index

    **UserRepository.java** — MyBatis-Plus BaseMapper<User>, includes findByEmail(String) returning Optional<User>

    **UserDetailsServiceImpl.java** — implements UserDetailsService, loadUserByUsername returns UserDetails from userRepository.findByEmail

    **JwtAuthenticationFilter.java** — per 01-RESEARCH.md Pattern 1:
    - extends OncePerRequestFilter
    - resolveToken(request) — extracts "Bearer <token>" from Authorization header
    - doFilterInternal: if token valid + no existing auth → set UsernamePasswordAuthenticationToken in SecurityContextHolder
    - Run BEFORE UsernamePasswordAuthenticationFilter

    **JwtAuthenticationEntryPoint.java** — returns 401 with JSON {"error": "Unauthorized"} for unauthenticated requests

    **SecurityConfig.java** — per 01-RESEARCH.md Pattern 3:
    - @Bean SecurityFilterChain with:
      - csrf disable
      - STATELESS session
      - exceptionHandling with entryPoint
      - authorizeHttpRequests: permit /api/auth/register, /api/auth/login, /api/auth/refresh, /api/auth/logout, OPTIONS /**
      - anyRequest().authenticated()
      - addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class)
    - @Bean PasswordEncoder (BCryptPasswordEncoder)
    - @Bean CorsConfigurationSource with allowedOrigins for localhost:5173

    **DTOs:**
    - RegisterRequest: email (valid email format), password (min 8 chars)
    - LoginRequest: email, password
    - AuthResponse: accessToken, refreshToken, tokenType="Bearer", expiresIn=900
    - RefreshRequest: refreshToken

    **Exceptions:**
    - EmailAlreadyExistsException (extends RuntimeException)
    - InvalidPasswordException (extends RuntimeException)
    - GlobalExceptionHandler: handles EmailAlreadyExistsException → 400, InvalidPasswordException → 400, BadCredentialsException → 401, all others → 500

    **AuthService.java:**
    - register(email, password): check email unique → BCrypt.encode(password) → save User → return userId
    - login(email, password): findByEmail → BCrypt.matches → generateAccessToken + generateRefreshToken → return AuthResponse
    - Throw BadCredentialsException for login failures (same message for wrong email or wrong password — no enumeration)

    **AuthController.java:**
    - POST /api/auth/register → authService.register → 201 {message, userId}
    - POST /api/auth/login → authService.login → 200 AuthResponse
    - POST /api/auth/refresh → authService.refresh → 200 AuthResponse (stub, full impl in Plan 02)
    - POST /api/auth/logout → 200 {message} (stub, full impl in Plan 03)

## Backend API Verification

Register a new user:
```bash
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"password123"}'
# Expected: 201 {"message":"User registered successfully","userId":1}
```

Login with registered user:
```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"password123"}'
# Expected: 200 {"accessToken":"eyJ...","refreshToken":"eyJ...","tokenType":"Bearer","expiresIn":900}
```

Access protected endpoint with token:
```bash
curl http://localhost:8080/api/auth/userinfo \
  -H "Authorization: Bearer <accessToken>"
# Expected: 200 with user info
```

Access protected endpoint without token:
```bash
curl http://localhost:8080/api/auth/userinfo
# Expected: 401 {"error":"Unauthorized"}
```

H2 console: http://localhost:8080/h2-console (JDBC URL: jdbc:h2:mem:aikb)
